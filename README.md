# FLRAD — лендинг

Готовый статический лендинг FLRAD.

Для публикации через GitHub Pages загрузите содержимое этой папки в корень репозитория: `index.html`, `styles.css`, `app.js` и папку `assets`. Затем откройте **Settings → Pages** и выберите публикацию из ветки `main` и папки `/ (root)`.

Кнопки лендинга ведут в Telegram-бота `@FreeRad_bot`.
